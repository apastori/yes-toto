yes-toto — C language standard and toolchain
============================================

Program version : 1.0.0  (YES_TOTO_VERSION_STRING in include/yes_toto.h)

C standard      : ISO/IEC 9899:2011 (C11)
Compiler flag   : -std=c11

Why C11
-------
- Project specification requires C11.
- static inline functions in headers (fill_buffer in include/yes_toto.h).
- Consistent, portable baseline across Linux and MSYS2 UCRT64 (MinGW-w64).
- No C++ features; compiled as C only.

POSIX feature macro
-------------------
-D_POSIX_C_SOURCE=200809L

Exposes POSIX.1-2008 interfaces used on Linux, notably:
  - write(2)           (unistd.h)   — hot output loop
  - isatty(3)          (unistd.h)   — TTY vs pipe output mode
  - sigaction(2)       (signal.h)   — SIGPIPE ignore, SIGINT handler (Linux)

On Windows (_WIN32), install_sigpipe_ignore() is a no-op; there is no
SIGPIPE. Broken pipes are handled via write() and errno (EPIPE or EINVAL);
maybe_normalize_broken_pipe_errno() in yes_toto_write.c remaps EINVAL on
pipe fds to EPIPE.

Output modes (yes_toto_run in yes_toto_write.c)
------------------------------------------------
- Terminal (isatty(STDOUT_FILENO)): one line per outer loop — same idea as
  GNU yes (fwrite one line); keeps Git Bash, UCRT64, cmd, and PowerShell
  responsive; Ctrl+C checked between writes.
- Pipe / redirect: fill_buffer() + 64 KiB write loop for throughput.

Interrupt handling (yes_toto_cli.c)
-----------------------------------
- install_sigint_handler(): SIGINT sets yes_toto_stop_requested; the write
  loop on the main thread calls _exit(130). Handlers do not call _exit
  directly (avoids frozen MSYS/Git Bash PTYs). No SetConsoleCtrlHandler.
- EINTR from write(): _exit(130).

Release compiler flags (from Makefile)
--------------------------------------
-std=c11
-Wall -Wextra -Wpedantic -Werror
-D_POSIX_C_SOURCE=200809L
-Iinclude
-O2

Build layout (from Makefile)
----------------------------
Objects and binaries are written under build/:
  build/.gitkeep         — keeps directory in git
  build/*.o              — from src/*.c (gitignored)
  build/yes-toto         — release binary (gitignored)
  build/yes-toto-debug   — sanitizer/debug binary (gitignored)
  build/tests/.gitkeep   — keeps tests subdirectory in git
  build/tests/*.o        — from tests/*.c (gitignored)
  build/tests/test_core  — unit-test binary (gitignored)

make clean removes artefacts only; .gitkeep scaffolding remains.

Debug / sanitizer build (make debug)
------------------------------------
Adds: -g -O1 -fsanitize=address,undefined -fno-omit-frame-pointer
Links build/yes-toto-debug in one step from sources (does not reuse release .o).

Supported compilers
-------------------
- GCC (preferred), or Clang if GCC is absent (see Makefile CC selection)
- Linux: native gcc/clang
- Windows: MSYS2 UCRT64 — mingw-w64-ucrt-x86_64-gcc

Libraries
---------
libc only. No third-party -l dependencies.

C standard library headers used (representative)
------------------------------------------------
<stddef.h>   size_t
<string.h>   memcpy, memset, strlen, strcmp
<stdio.h>    printf, fprintf, fflush (not in hot loop)
<stdlib.h>   malloc, exit
<errno.h>    errno, strerror
<signal.h>   sigaction, SIGINT, SIGPIPE (yes_toto_cli.c)
<unistd.h>   write, isatty, STDOUT_FILENO
<assert.h>   unit tests only
