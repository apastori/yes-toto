yes-toto — C language standard and toolchain
============================================

Program version : 1.0.0  (YES_TOTO_VERSION_STRING in include/yes_toto.h)

C standard      : ISO/IEC 9899:2011 (C11)
Compiler flag   : -std=c11

Why C11
-------
- Project specification requires C11.
- static inline functions in headers (fill_buffer in include/yes_toto.h).
- Consistent, portable baseline across Linux and MSYS2 UCRT64 (MinGW-w64).
- No C++ features; compiled as C only.

POSIX feature macro
-------------------
-D_POSIX_C_SOURCE=200809L

Exposes POSIX.1-2008 interfaces used on Linux, notably:
  - write(2)           (unistd.h)   — hot output loop
  - sigaction(2)       (signal.h)   — SIGPIPE ignore (Linux only)

On Windows (_WIN32), install_sigpipe_ignore() is a no-op; there is no
SIGPIPE. Broken pipes are handled via write() and errno (often EPIPE).

Release compiler flags (from Makefile)
--------------------------------------
-std=c11
-Wall -Wextra -Wpedantic -Werror
-D_POSIX_C_SOURCE=200809L
-Iinclude
-O2

Debug / sanitizer build (make debug)
------------------------------------
Adds: -g -O1 -fsanitize=address,undefined -fno-omit-frame-pointer

Supported compilers
-------------------
- GCC (preferred), or Clang if GCC is absent (see Makefile CC selection)
- Linux: native gcc/clang
- Windows: MSYS2 UCRT64 — mingw-w64-ucrt-x86_64-gcc

Libraries
---------
libc only. No third-party -l dependencies.

C standard library headers used (representative)
------------------------------------------------
<stddef.h>   size_t
<string.h>   memcpy, memset, strlen, strcmp
<stdio.h>    printf, fprintf, fflush (not in hot loop)
<stdlib.h>   malloc, exit
<errno.h>    errno, strerror
<signal.h>   sigaction, SIGPIPE (Linux path in yes_toto_cli.c)
<unistd.h>   write, STDOUT_FILENO
<assert.h>   unit tests only
